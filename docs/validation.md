# Validation plan

Internal performance is not clinical validation.

## Development validation
- leakage checks
- repeated cross-validation
- calibration
- bootstrap uncertainty
- threshold analysis

## External validation
Use samples from veterinary sites not used for model development. Report ROC-AUC with CI, sensitivity, specificity, PPV/NPV at observed prevalence, calibration, subgroup performance, missing-data sensitivity, and site variability.

## Prospective validation
Before clinical deployment, evaluate a frozen model prospectively in the workflow where it is expected to be used.
